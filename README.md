# DefinitelyNotAI

AskWRI: a cited research assistant over World Resources Institute publications, built on
Amazon Bedrock and AgentCore for an AWS hackathon.

## Getting started

1. Clone the repo and open it in Claude Code or Codex.
2. Run the setup skill: `/setup` in Claude Code, `$setup` in Codex.
3. Claim a task with `claim-task`, do the work, then finish with `create-pr` (or `handoff`
   if you stop partway).

Rules for humans and agents are in [AGENTS.md](AGENTS.md).
